# Contributing

Kilometry is intentionally kept minimal. Keep that in mind before proposing a large feature. See the README.

## Workflow

1. Fork the repo and create a branch: `feature/name` or `fix/name`.
2. Make sure `npm run lint` and `npm run build` pass before opening a PR.
3. Open a pull request against `main` with a short description of what and why.
4. The repo owner reviews and merges manually. No auto-merge.

## Issues

Bugs and feature requests are welcome as issues. This project's scope stays intentionally small, so discuss larger feature proposals in an issue first before opening a PR for one.
